Soal 2 · Mean, Variansi, IQR & CV 20 poin

Waktu tunggu 15 pelanggan: 8, 10, 11, 12, 12, 13, 14, 15, 15, 16, 18, 20, 22, 24, 25
Langkah Hitung Rinci
  • a) Mean (x̄):
    Σ X = 8 + 10 + 11 + … + 25 = 235.
    x̄ = Σ Xn = 23515 = 15,67 menit.
  • b) Median:
    Data sudah urut naik. n = 15 (ganjil). Posisi median = 15+12 = 8. Data ke-8 = 15 menit.
  • c) Modus:
    Angka 12 muncul 2 kali, angka 15 juga 2 kali. Bimodal (12 dan 15).
  • d) Variansi Sampel (s²):
    Σ X² = 8² + 10² + 11² + … + 25² = 64 + 100 + 121 + 144 + 144 + 169 + 196 + 225 + 225 + 256 + 324 + 400 + 484 + 576 + 625 = 4.053.
    Rumus shortcut: s² = Σ X² - (Σ X)²nn - 1 = 4053 - 235²1514 = 4053 - 552251514 = 4053 - 3681,6714 = 371,3314 = 26,52.
    s = √26,52 = 5,15 menit.
  • e) Kuartil (Metode Levine) & IQR:
    Posisi Q₁ = n+14 = 164 = 4 → data ke-4 = 12.
    Posisi Q₃ = 3(n+1)4 = 484 = 12 → data ke-12 = 20.
    IQR = Q₃ - Q₁ = 20 - 12 = 8 menit.
  • f) CV:
    CV = sx̄ × 100% = 5,1515,67 × 100% = 32,86%. (Variabilitas sedang.)
  • g) Deteksi Outlier:
    Pagar bawah = Q₁ - 1,5 × IQR = 12 - 12 = 0.
    Pagar atas = Q₃ + 1,5 × IQR = 20 + 12 = 32.
    Data minimum 8 ≥ 0 dan data maksimum 25 ≤ 32, maka tidak ada outlier.
  • h) Bentuk distribusi:
    Mean 15,67 > Median 15,00. Artinya ekor data memanjang ke kanan → menceng kanan (positif / right-skewed).
🆕 Study Case 2 — Data Baru:

Skor kepuasan pelanggan 11 orang: 3, 4, 5, 5, 6, 7, 7, 7, 8, 9, 15.

Soal: (a) Mean, (b) Median, (c) Variansi sampel, (d) Q₁, Q₃, IQR, (e) Ada outlier?, (f) Menceng ke mana?

  • (a) Σ X = 76, x̄ = 76 / 11 = 6,91.
  • (b) n = 11 ganjil. Posisi (11+1)/2 = 6. Data ke-6 = 7.
  • (c) Σ X² = 580. s² = (580 - 76²/11) / 10 = (580 - 525,09) / 10 = 54,91 / 10 = 5,49. s = 2,34.
  • (d) Q₁ posisi (11+1)/4 = 3 → data ke-3 = 5. Q₃ posisi 3 × 12/4 = 9 → data ke-9 = 8. IQR = 8 - 5 = 3.
  • (e) Pagar bawah = 5 - 4,5 = 0,5; pagar atas = 8 + 4,5 = 12,5. Nilai 15 > 12,5, maka 15 adalah outlier!
  • (f) Mean 6,91 < Median 7. Tapi ada outlier di kanan... Sebenarnya 6,91 < 7 menunjukkan distribusi yang kira-kira simetris, tapi outlier 15 di kanan menandakan ada ekor panjang kanan. Secara numeris strict: menceng kiri sedikit (mean < median), namun secara visual karena outlier di kanan, bentuknya mendekati simetris dengan outlier kanan. Di ujian, pakai acuan mean vs median: mean < median → menceng kiri.

Soal 3 · Distribusi Probabilitas Diskrit 20 poin

Jumlah barang rusak per hari (X)
X01234Σ
P(X = x)0,100,250,350,200,101,00
Bedah Jawaban Lengkap
  • a) Apakah distribusi ini sah / valid?
    Syarat: (1) Semua P(x) ≥ 0 ✓ (semuanya positif). (2) Σ P(x) = 0,10 + 0,25 + 0,35 + 0,20 + 0,10 = 1,00 ✓.
    Sah!
  • b) P(X ≥ 3):
    X ≥ 3 artinya X = 3 atau X = 4 → P(3) + P(4) = 0,20 + 0,10 = 0,30.
    P(X ≤ 1) = P(0) + P(1) = 0,10 + 0,25 = 0,35.
  • c) P(1 < X ≤ 3):
    Perhatikan! Tanda "<" (bukan ≤) berarti 1 tidak ikut. Yang masuk: X = 2 dan X = 3.
    P(2) + P(3) = 0,35 + 0,20 = 0,55.
  • d) Expected Value E(X):
    E(X) = Σ x · P(x) = (0)(0,10) + (1)(0,25) + (2)(0,35) + (3)(0,20) + (4)(0,10)
    = 0 + 0,25 + 0,70 + 0,60 + 0,40 = 1,95 unit/hari.
  • e) Variansi Var(X):
    Σ x² P(x) = (0)(0,10) + (1)(0,25) + (4)(0,35) + (9)(0,20) + (16)(0,10) = 0 + 0,25 + 1,40 + 1,80 + 1,60 = 5,05.
    Var(X) = 5,05 - (1,95)² = 5,05 - 3,8025 = 1,2475.
    σ = √1,2475 = 1,117 unit.
  • f) Jika biaya harian C = 10.000 + 25.000 × X:
    E(C) = 10.000 + 25.000 × E(X) = 10.000 + 25.000 × 1,95 = 10.000 + 48.750 = Rp 58.750.
🆕 Study Case 3 — Binomial:

Sebuah mesin produksi memiliki tingkat cacat 8% (p = 0,08). Diambil sampel acak n = 5 produk.

Soal: (a) P(X = 0) (tidak ada yang cacat)? (b) P(X ≥ 2)? (c) E(X)?

  • (a) P(X=0) = ₅C₀ × 0,08⁰ × 0,92⁵ = 1 × 1 × 0,6591 = 0,6591.
  • (b) P(X ≥ 2) = 1 - P(0) - P(1) = 1 - 0,6591 - [₅C₁ × 0,08 × 0,92⁴] = 1 - 0,6591 - [5 × 0,08 × 0,7164] = 1 - 0,6591 - 0,2866 = 0,0543.
  • (c) E(X) = np = 5 × 0,08 = 0,40 (rata-rata 0,4 produk cacat per 5 sampel).

Soal 4 · Distribusi Normal & Z-Score 20 poin

Nilai ujian berdistribusi normal: μ = 72, σ = 8
Bedah Jawaban Lengkap
  • a) P(X < 60):
    Standarisasi: Z = 60 - 728 = -128 = -1,50.
    Buka Tabel Z, baris -1,5 kolom 0,00 → P(Z < -1,50) = 0,0668.
    Artinya 6,68% mahasiswa nilainya di bawah 60.
  • b) P(60 < X < 80):
    Z60 = -1,50 → luas kiri = 0,0668.
    Z80 = 80 - 728 = 88 = +1,00 → luas kiri = 0,8413.
    P(60 < X < 80) = 0,8413 - 0,0668 = 0,7745 (77,45%).
  • c) P(X > 85):
    Z = 85 - 728 = 138 = +1,63 → luas kiri = 0,9484.
    P(X > 85) = 1 - 0,9484 = 0,0516 (5,16%).
  • d) Berapa batas nilai 10% mahasiswa teratas?
    10% teratas artinya 90% ada di bawahnya → cari luas kiri = 0,9000.
    Di tabel Z: Z ≈ 1,28 (baris 1,2 kolom 0,08 → 0,8997, paling dekat 0,9000).
    Konversi balik: X = μ + Z × σ = 72 + 1,28 × 8 = 72 + 10,24 = 82,24.
  • e) P(X < 58) (Tidak lulus):
    Z = 58 - 728 = -148 = -1,75 → luas kiri = 0,0401 (4,01%).
⚠️ Jebakan "10% teratas": Banyak mahasiswa langsung mencari angka 0,10 di tabel Z. Padahal tabel memberikan luas ke kiri! Jadi yang harus dicari di tabel adalah 1 - 0,10 = 0,9000 (luas KIRI dari batas teratas).
🆕 Study Case 4 — Data Baru:

Berat kemasan produk berdistribusi normal dengan μ = 500g dan σ = 12g.

Soal: (a) P(X < 480)? (b) P(490 < X < 510)? (c) Berapa batas berat agar masuk 5% terberat?

  • (a) Z = (480-500)/12 = -1,67 → tabel = 0,0475 (4,75%).
  • (b) Z490 = -0,83 → 0,2033; Z510 = +0,83 → 0,7967. Jawaban = 0,7967 - 0,2033 = 0,5934 (59,34%).
  • (c) 5% terberat → luas kiri = 0,9500 → Z ≈ 1,645. X = 500 + 1,645 × 12 = 500 + 19,74 = 519,74g.

Soal 5 · Box Plot & Interpretasi 20 poin

Five-Number Summary dua kelas
StatistikKelas AKelas B
Minimum4540
Q₁6255
Median (Q₂)7468
Q₃8285
Maksimum9598
Bedah Jawaban Lengkap
  • a) IQR setiap kelas:
    IQRA = Q₃ - Q₁ = 82 - 62 = 20; IQRB = 85 - 55 = 30.
  • b) Pagar outlier Kelas B:
    Lower Fence = Q₁ - 1,5 × IQR = 55 - 1,5(30) = 55 - 45 = 10.
    Upper Fence = Q₃ + 1,5 × IQR = 85 + 45 = 130.
    Data B: Min 40 ≥ 10 dan Maks 98 ≤ 130, jadi tidak ada outlier.
  • c) Kelas mana yang nilainya lebih tinggi?
    Bandingkan median: Kelas A median 74 > Kelas B median 68. Kelas A lebih tinggi.
  • d) Kelas mana yang lebih menyebar?
    Bandingkan IQR: Kelas B IQR 30 > Kelas A IQR 20. Kelas B lebih menyebar.
  • e) Sketsa Box Plot Kelas B:
    Kotak dari 55 s/d 85, garis median vertikal di 68, kumis kiri ke 40, kumis kanan ke 98. Tidak ada titik outlier.
  • f) Bentuk distribusi Kelas B:
    Jarak median ke Q₁: 68 - 55 = 13.
    Jarak median ke Q₃: 85 - 68 = 17.
    Median lebih dekat ke Q₁ (13 < 17), artinya ada ekor yang lebih panjang ke arah kanan → menceng kanan (positif).
🆕 Study Case 5 — Data Baru:

Data gaji bulanan (juta Rp) 9 karyawan: 3, 4, 5, 5, 6, 7, 8, 10, 22.

Soal: (a) Q₁, Q₃, IQR? (b) Pagar outlier? (c) Ada outlier? (d) Bentuk distribusi?

  • (a) n = 9. Posisi Q₁ = (9+1)/4 = 2,5 → rata-rata data ke-2 dan ke-3 = (4+5)/2 = 4,5. Q₃ posisi 7,5 → (8+10)/2 = 9. IQR = 9 - 4,5 = 4,5.
  • (b) Lower = 4,5 - 6,75 = -2,25. Upper = 9 + 6,75 = 15,75.
  • (c) 22 > 15,75 → 22 adalah outlier!
  • (d) Mean = 70/9 = 7,78, Median = 6. Mean > Median → menceng kanan (diperkuat oleh adanya outlier 22 di kanan).

Rumus Cepat

P(A|B) = P(A∩B) / P(B)
s² = [ΣX² − (ΣX)²/n] / (n−1)
Z = (X − μ) / σ
IQR = Q3 − Q1
E(X) = Σ x·P(x)
Var = Σx²P(x) − μ²
