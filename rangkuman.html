Bab 1 · Defining & Collecting Data

Klasifikasi Variabel, Skala NOIR, Teknik Sampling, Survey Errors
1. Pohon Klasifikasi Variabel
KlasifikasiSub-TipeDefinisiContoh Ujian
Kategorik
Label / kelompok		 Nominal Nama label pembeda, tanpa urutan. Jenis kelamin, merek HP, jurusan, NIM.
Ordinal Kategori punya urutan, selisih tidak pasti. Rating 1–5, ukuran S/M/L/XL, ranking.
Numerik
Angka hitung / ukur		 Diskrit Hasil MENGHITUNG (bilangan bulat). Jumlah keluhan, banyak SMS, jumlah bug.
Kontinu Hasil MENGUKUR (bisa desimal). Waktu download, suhu °C, berat kg.
2. Skala Pengukuran NOIR
  • Nominal: Cuma label pembeda, tidak bisa diurutkan.
  • Ordinal: Punya urutan, jarak antar peringkat tidak bermakna pasti.
  • Interval: Jarak bermakna, tapi NOL BUKAN mutlak. Contoh: Suhu 0circC masih ada panas.
  • Rasio: Jarak bermakna DAN NOL = ketiadaan total. Contoh: Rp 0 = tidak ada uang.
3. Metode Sampling
MetodeCara KerjaKeunggulan / Kelemahan
Simple RandomPeluang sama rata, acak murni.Adil; butuh daftar lengkap populasi.
Systematick = N / n, ambil setiap ke-k.Praktis; bahaya pola tersembunyi.
StratifiedBagi jadi strata homogen, acak dari tiap strata.Minoritas terwakili proporsional.
ClusterPilih acak beberapa gugus, ambil semua di dalamnya.Hemat; variansi estimasi lebih besar.
4. Empat Survey Errors
  • Coverage Error: Kelompok populasi tidak terdaftar di kerangka sampel.
  • Nonresponse Error: Responden menolak / tidak bisa dihubungi.
  • Sampling Error: Selisih alami hasil sampel vs parameter populasi.
  • Measurement Error: Pertanyaan ambigu, alat rusak, responden bohong.

Bab 2 & 3 · Tabel Frekuensi & Ukuran Statistik

Distribusi Frekuensi, Mean, Median, Kuartil, Varians, Std Dev, CV, Outlier
1. Tabel Distribusi Frekuensi Kelompok
  1. Range: R = Xmax - Xmin
  2. Banyak Kelas: k = 1 + 3,322 log10(n) (bulatkan ke atas).
  3. Lebar Kelas: w = R / k (bulatkan ke atas).
2. Ukuran Pemusatan
  • Mean Sampel: x̄ = Σ xᵢn — Sensitif outlier.
  • Median: Urut kecil → besar, posisi = n + 12 — Tahan outlier.
  • Modus: Nilai yang frekuensinya terbanyak.
3. Kuartil, IQR, Deteksi Outlier
Posisi Kuartil:
Q₁ = n + 14  |  Q₂ = n + 12  |  Q₃ = 3(n + 1)4

Interquartile Range: IQR = Q₃ - Q₁ Pagar Outlier:
Batas Bawah = Q₁ - 1,5 × IQR  |  Batas Atas = Q₃ + 1,5 × IQR
Data di luar interval ini dinyatakan OUTLIER!
4. Varians, Standar Deviasi, CV
s² = Σ xᵢ² - (Σ xᵢ)²nn - 1 Longleftrightarrow s = √s² Koefisien Variasi: CV = (sx̄) × 100% CV makin kecil = data makin konsisten / stabil.

Bab 4 · Probabilitas & Tabel Kontingensi

Tabel Silang 2×2, Peluang Marginal, Joint, Bersyarat, Uji Independensi
1. Cara Baca Tabel Kontingensi 2×2
BBcTotal
An(A ∩ B) [Joint]n(A ∩ Bc)n(A) [Marginal]
Acn(Ac ∩ B)n(Ac ∩ Bc)n(Ac)
Totaln(B)n(Bc)N
2. Kamus Rumus Peluang
  • Marginal: P(A) = n(A)N
  • Joint (DAN): P(A ∩ B) = n(A ∩ B)N
  • Gabungan (ATAU): P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  • Bersyarat (JIKA): P(B | A) = P(A ∩ B)P(A) = n(A ∩ B)n(A) Pembagi berubah ke total baris A, bukan N!
  • Uji Independensi: P(A ∩ B) = P(A) × P(B) atau P(B | A) = P(B) Jika tidak sama → DEPENDEN.

Bab 5 · Distribusi Peluang Diskrit

E(X), Var(X), Binomial, Poisson, Hipergeometrik
1. Nilai Harapan & Varians
μ = E(X) = Σ [xᵢ · P(X = xᵢ)] σ² = Σ [xᵢ² · P(X = xᵢ)] - [E(X)]² Syarat: 0 ≤ P(x) ≤ 1 dan Σ P(x) = 1.
2. Pohon Keputusan Distribusi Diskrit
DistribusiCiri Khas SoalP(X = k)Mean & Var
Binomial
🏷️ VENOM-BINOM		 n percobaan tetap, 2 hasil, peluang π konstan (dengan pengembalian). nk πᵏ (1 - π)n - k E = nπ
V = nπ(1 - π)
Poisson
🏷️ CROISSANT-POIS		 Kejadian langka per satuan waktu/luas (rata-rata λ). e-λ · λᵏk! E = λ
V = λ
Hipergeometrik
🏷️ KARTU-HIPER		 N populasi, A sukses, ambil n tanpa pengembalian. Ak N - An - kNn E = n(A/N)
Jalan Pintas Komplemen: P(X ≥ 1) = 1 - P(X = 0). Jangan hitung satu per satu!

Bab 6 · Distribusi Normal & Z-Score

Standarisasi, 3 Pola Luas Tabel Z, Persentil Konversi Balik
1. Standarisasi Z
Z = X - μσ Longleftrightarrow X = μ + Z · σ Z = berapa standar deviasi posisi X dari rata-rata.
2. Tiga Pola Membaca Tabel Z (Cumulative Left Tail)
PertanyaanRumusCara Hitung
Kurang dari P(X < a) = P(Z < z) Langsung baca tabel Z.
Lebih dari P(X > a) = P(Z > z) 1 - P(Z < z)
Di antara P(a < X < b) P(Z < z₂) - P(Z < z₁)
3. Mencari Batas X dari Persentil

Langkah Cari Nilai X (Top k%)

  1. Top 10% → luas kiri = 0,9000. Cari angka itu di badan tabel Z → Z ≈ 1,28.
  2. X = μ + Z · σ.

Panduan Contekan 1 Lembar A4 (Tulis Tangan)

Strategi Menyusun Open Notes Bolak-Balik Sesuai Aturan Ujian

Ujian mengizinkan 1 lembar A4 tulis tangan bolak-balik. Jangan buang tempat buat kalimat panjang; tulis Rumus Baku + Bagan Alur + Nilai Z Kunci!

Sisi Depan (Bab 1, 2, 3):
  • NOIR: Nominal, Ordinal, Interval, Rasio.
  • Sturges: k = 1 + 3,322 log10(n), w = R/k.
  • Kuartil: Q₁ = (n+1)/4, Q₃ = 3(n+1)/4.
  • Outlier: Q₁ - 1,5 × IQR dan Q₃ + 1,5 × IQR.
  • Varians: s² = [Σ X² - (Σ X)² / n] / (n - 1).
  • CV: (s / x̄) × 100%.
  • Bersyarat: P(B|A) = P(A ∩ B) / P(A).
  • Independen: P(A ∩ B) = P(A) · P(B).
Sisi Belakang (Bab 4, 5, 6):
  • Binom: nk πᵏ (1-π)n-k, μ=nπ.
  • Poisson: (e-λ λᵏ)/k!, μ=λ, σ²=λ.
  • Hiper: [AkN-An-k] / Nn.
  • Z-score: Z = (X - μ)/σ, X = μ + Zσ.
  • Nilai Z Penting:
    90% → 1,28 · 95% → 1,645 · 97,5% → 1,96 · 99% → 2,33
  • Template Kesimpulan: subjek + persentase + satuan.

Jebakan Ujian ⚠️

• NIM / No Telp: Nominal, bukan Rasio.
• Suhu Celsius: Interval, bukan Rasio.
• P(A|B): Pembagi = total B, bukan Grand Total!
• Varians sampel: Bagi n-1, bukan n!
• Per Jam = Poisson. Tanpa Ganti = Hiper.
